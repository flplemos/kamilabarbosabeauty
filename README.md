# Kamila Barbosa Beauty · página do QR code

Página estática (HTML + CSS, sem JavaScript) para onde aponta o QR code impresso na porta do studio.

Endereço publicado: https://flplemos.github.io/kamilabarbosabeauty/

## Importante

O QR code está impresso na porta. Para ele continuar funcionando:

- **não renomear** este repositório nem o usuário `flplemos`;
- **não apagar/arquivar** o repositório nem desativar o GitHub Pages;
- manter o arquivo `index.html` na raiz da branch `main`.

Se um dia houver domínio próprio, configure-o em *Settings → Pages → Custom domain*: o GitHub redireciona o endereço antigo automaticamente e o QR continua valendo.

## Publicar

*Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)`*.
